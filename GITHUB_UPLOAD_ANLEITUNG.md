# GitHub-Upload (Schritt für Schritt)

1. Dieses ZIP-Paket entpacken (Windows: Rechtsklick → Alle extrahieren).
2. Auf https://github.com/new gehen und ein neues Repository mit dem Namen `immobilien-reservierungsverwaltung` erstellen.
3. Vorerst **Private** auswählen und bei „Add a README file“ kein Häkchen setzen.
4. Auf „Create repository“ klicken.
5. Im leeren Repository „uploading an existing file“ wählen.
6. Aus dem **entpackten** Projektordner die sichtbaren Dateien und Ordner in das Uploadfeld ziehen. Auch die versteckte Datei `.gitignore` hochladen (Windows: „Ansicht → Einblenden → Ausgeblendete Elemente“).
7. Commit message: `Add real estate reservation management project`.
8. Mit „Commit changes“ oder „Commit files“ bestätigen.
9. Die README.md wird automatisch unter der Dateiliste angezeigt.
10. Vor dem Umstellen auf „Public“: Zustimmung der Teammitglieder einholen und Dateien auf vertrauliche Daten prüfen.

**Nicht hochladen:** Original-7z-Datei, `backend/db.json`, `node_modules`, echte Ausweisdaten, Passwörter, vollständige PDF-Deckblätter mit Team-Personendaten.
